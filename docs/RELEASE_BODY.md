## Local Music Hub 0.13.22

### Media keyboard keys
- **Play/Pause**, **Next**, **Previous**, and **Stop** work **globally** — including when Local Music Hub is in the tray or another app is focused.
- Previously these keys only reached LMH when its window was focused.
- Play/Pause also starts the current selection when nothing is queued (same as the toolbar button).

Install **`LocalMusicHub-Setup-0.13.22.exe`** from this release. Your library under `%LocalAppData%\LocalMusicHub\` is kept.
